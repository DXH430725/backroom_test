# 第 4 集 · LEVEL 881 —「窗之庭院」The Courtyard of Windows

M.E.G. 指南针点团「猫头鹰之眼」小队于 2017 年 1 月进入，没有回来。本集是他们部分回收的头盔摄像机日志。约 3 分 18 秒。

**成片（1080p 压缩版）：`out/ep04_level881/ep04_level881_1080p_web.mp4`**

## 设定依据（Backrooms Wiki · Level 881 "The Courtyard of Windows"）

- 生存难度 5：出口 5/5（死路）、环境 4/5、实体 5/5。页面的原话是：**不要进入窗之庭院。**
- 一座不规则的室内中庭，直径约 45 米、高约 30 米，四周是朴素的白色混凝土墙。
- 墙上均匀分布着一两百扇窗，大多拉着百叶帘。其中四分之一到几乎全部，已经被「窗户实体」取代。有些窗后能看到人影。
- 地面：一圈五边形的铺石小径，有四条岔路通向中央一块浅色白桦木圆盘。圆盘是空心的，不是出口。小径之间是活的苔藓。
- 恒温 13.8°C，通常一片死寂。有记录的声音包括留声机音乐、有节奏的撞击声和吱嘎声。
- 物体会凭空出现，比如桌子、留声机、闹钟和《了不起的盖茨比》。桌子会自己移动。
- 墙上偶尔会出现桃花心木门，门后是刺眼的白色走廊，有穿粉色裙子的无面者。
- 2017 年远征的日志：
  - 入口窗户消失，小队被困。
  - 四小时后桌子移到了中央，窗户全部换了位置，留声机开始播放。
  - 队员一个接一个消失。最后只剩 Fassbender 中尉，他发现书里的文字出了错。
- 安全规程：
  - 音乐响起时立刻离开。
  - 如果被困，就遮住自己、蒙眼、堵耳，忽略一切声音和幻象 6–8 小时。那些幻象「不是真的」。
