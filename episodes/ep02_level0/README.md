# 第 2 集 · LEVEL 0 —「门槛」Threshold

一卷来自身份不明流浪者的录像。他「掉出了现实」，醒来时躺在潮湿的地毯上。约 3 分 25 秒。

**成片（1080p 压缩版）：`out/ep02_level0/ep02_level0_1080p_web.mp4`**

## 设定依据（Backrooms Wiki · Level 0 "Threshold"）

- 病态的黄色墙纸，潮湿发霉的地毯，忽大忽小、有时刺耳的日光灯嗡鸣。是一座绵延数英里的分段房间迷宫。
- **外围位移**：没有人看着的时候，布局会改变，可能抹掉好几天的进度。
- 子区域：
  - **柱厅**：广阔的网格状柱子房间。建议选定一个方向一直走。
  - **坑洞**：成网格排列的漆黑深坑。
  - **停电区**：没有灯光，地上积着没过脚踝的液体。
  - **红房间**：几乎无法逃出的闭环。颜色发红、地毯变黏时要立刻掉头。
  - **拱门区**：整个层级最稳定的地方。
- 会听到墙里的刮擦声和低语，以及熟悉的声音在呼唤你。设定的建议是不要理会。
- 有报告称走廊里出现过黑色人影，但实体未确认。
- **隔离效应**：同时进入的人无法找到彼此。
- 入口：从现实中「掉出来」。出口：穿过一面闪烁的墙，到达 Level 1。生存难度 1。

## 渲染

```bash
episodes/ep02_level0/render_1080p.sh
episodes/ep02_level0/render_4k.sh
episodes/ep02_level0/remix_audio.sh     # 配音到位后
```

- 画面用 `backrooms/gridworld.py` 的逐像素网格光线投射器渲染。所有子区域放在同一张地图里，外围位移通过在不同时刻切换三套墙体数据实现。
- 配音台本在 `voice/lines.json`，共 20 句，角色是档案员、拍摄者和「熟悉的声音」。
