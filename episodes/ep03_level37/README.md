# 第 3 集 · LEVEL 37 —「崇高」Sublimity（泳池房）

## 设定依据（Backrooms Wiki · Level 37 "Sublimity"）

- 由房间、走廊、泳池和开阔区域连成的庞大建筑群。柱子从水中升起，楼梯有时会一直向下通进深坑。
- 几乎所有表面都是崭新完美、无法破坏的白色瓷砖。
- 水是温的，呈蓝绿色，始终在轻轻起伏，像有潮汐。水中含泻盐，能放松肌肉、缓解疼痛。
- 光线从不规则的角度照进来，有些区域一片漆黑。
- 声学异常：声音会突然消失，回声不对劲，说话听起来发闷。
- 没有实体，没有基地。深处危险，主要因为照明差、出口少、有溺水风险。生存难度 0。
- 入口：潜入 Level 58、119 的水中等。出口：沉入水中可能会浮到 Level 130；黑暗的隧道可能通往 Level 43。
- 日志原话："indescribably strange, yet indescribably perfect."（难以形容地奇怪，又难以形容地完美）
